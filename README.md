# Task Chatbot 🤖

An AI-powered Task Management Chatbot that helps users create, manage, organize, and track tasks efficiently through a conversational interface.

---

## 🚀 Features

- ✅ User Authentication (Login/Register)
- ✅ Create, Update, Delete Tasks
- ✅ AI Chatbot Assistance
- ✅ Task Prioritization
- ✅ Due Date Management
- ✅ Task Status Tracking
- ✅ Real-time Chat Interface
- ✅ Responsive Frontend
- ✅ REST API Integration
- ✅ Secure Backend Authentication using JWT

---

## 🛠️ Tech Stack

### Frontend
- React.js
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

- MongoDB

- Grok API
